# Al Madani Development Engineering Consultancy Company Web Application

A company-focused web application developed for an engineering consultancy firm in Muscat, Oman. The application is built using Django and provides a fully functional platform featuring core company information, services, and an integrated AI chatbot to assist users with queries.
